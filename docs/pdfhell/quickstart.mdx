title: "Quickstart"
description: "Install PDF Hell 0.6.1 and run a reproducible adversarial document benchmark."
---

PDF Hell stress-tests AI document readers with PDFs generated from code. The
generator chooses the answer before drawing each document, so scoring uses
procedural ground truth rather than an LLM judge.

## Install and authenticate

```bash
pip install pdfhell
export GOOGLE_API_KEY=...
```

You can also run without a permanent install by replacing `pdfhell` with
`uvx pdfhell`. Use the environment variable for your chosen provider:
`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, or `GOOGLE_API_KEY`.

## Run a suite

```bash
# Three-case wiring check
uvx pdfhell run --model google:gemini-2.5-flash --suite smoke

# Current 17-family sample: 170 cases
uvx pdfhell run --model google:gemini-2.5-flash --suite mini-v4-sample

# Full current suite: 510 cases
uvx pdfhell run --model google:gemini-2.5-flash --suite mini-v4
```

The runner materializes missing cases, sends each PDF to the selected model,
and writes a JSON report under `runs/`. Use `--out`, `--junit`,
`--audit-pack`, and `--fail-threshold` to make those artifacts explicit.

## Inspect one trap

```bash
pdfhell list-traps
pdfhell make --trap unicode_confusable_total --seed 7001
```

The same family and seed reproduce the same PDF and answer key.

## Isolate visual reading

Provider PDF APIs may use the embedded text layer, rendered pixels, or both.
Pixels-only mode rasterizes locally and sends PNG pages instead:

```bash
pip install 'pdfhell[pixels]'
pdfhell run --model anthropic:claude-haiku-4-5 --suite smoke --pixels
```

The default is 150 DPI; override it with `--dpi`. Reports record the modality,
DPI, and pdfium build. Do not compare PDF and pixels-only scores as though they
were the same experiment.

<Warning>
Use PDF Hell 0.6.1 or newer for `zero_width_space_split` and
`unicode_confusable_total`. Earlier generators could render visible replacement
glyphs, so old results for those two families are not comparable with current
runs.
</Warning>

## Discover new traps

The optional research package provides the budgeted autoresearch loop used to
propose and validate new families:

```bash
pip install 'pdfhell[research]>=0.5.4'
python -m pdfhell.research.loop --budget 50 --max-candidates 200
python -m pdfhell.research.report
python -m pdfhell.research.curate --promotion-plan
```

Start with `mini-v4-sample` for routine comparisons and use `mini-v4` when you
need tighter per-family estimates. Always retain the suite hash from the report.
